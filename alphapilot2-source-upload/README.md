# AlphaPilot

AlphaPilot is a public-ready AI trading intelligence platform being built private-beta first.

Initial focus:

- AI market analysis, setup scoring, and guided trade plans
- Copilot mode for research, briefings, journal insight, and risk commentary
- Drive mode for manual execution guidance: entry, stop, targets, and risk notes
- Optional advanced connector architecture for private MT5, Binance, and Hyperliquid integrations

Never commit real broker credentials, API keys, wallet private keys, or MT5 passwords.
